# E-commerce UI Improvement

## 1. Giới thiệu dự án
Cải tiến giao diện thương mại điện tử siêu thị trực tuyến **Bách Hóa XANH** bằng HTML5 và CSS3 (Responsive Mobile-first & Desktop).

## 2. Cấu trúc thư mục
```text
bach-hoa-xanh/
├── index.html
├── gio-hang.html
├── css/
│   ├── style.css
│   └── gio-hang.css
├── images/
│   └── product-demo.jpg
├── README.md
└── AI_USAGE.md
```

## 3. Hướng dẫn chạy bài tập
1. Tải hoặc clone repository về máy tính.
2. Mở thư mục dự án bằng **Visual Studio Code**.
3. Mở tệp `index.html` trực tiếp bằng trình duyệt web hoặc chạy qua tiện ích **Live Server**.
