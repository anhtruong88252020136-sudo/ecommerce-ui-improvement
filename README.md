BÁCH HÓA XANH – GIAO DIỆN MINH HỌA HTML5/CSS3

Cấu trúc:
- index.html: cấu trúc trang và nội dung mẫu.
- style.css: toàn bộ định dạng và responsive.

Cách chạy:
1. Giải nén thư mục.
2. Mở thư mục bằng VS Code hoặc trình soạn thảo bất kỳ.
3. Mở index.html trực tiếp bằng trình duyệt (Chrome, Edge, Firefox).
   Có thể dùng tiện ích Live Server trong VS Code nếu đã cài.

Lưu ý:
- Đây là giao diện tĩnh, không có backend/cơ sở dữ liệu.
- Nút "Thêm" và ô tìm kiếm chỉ là thành phần giao diện, chưa xử lý nghiệp vụ.
- Hình ảnh sản phẩm tải từ Unsplash nên cần kết nối Internet.
- Tên sản phẩm, giá và thông tin thương hiệu là dữ liệu minh họa, không đại diện giá bán thực tế.
- Sticky Anchor Tabs dùng liên kết neo HTML và CSS scroll-behavior.
- Tự động đổi trạng thái tab theo vị trí cuộn cần JavaScript; hiện tab đầu tiên được đánh dấu active mặc định.
